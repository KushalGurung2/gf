# Happy Girlfriend Day ❤️

A romantic, animated surprise website.

## How to open it
Just open **index.html** in any browser. That's it.

## How to make it yours (everything is in one place)
Open **script.js** and edit the **CONFIG block at the very top**. You can change:

- **Names** — `herName`, `yourName`
- **Relationship start date** — `startDate` (⚠️ months are 0–11, so January = 0, December = 11)
- **Music** — drop an mp3 in `assets/music/` and set `musicSrc`
- **Love letter** — `letter`
- **Photos** — `gallery` (add your images to `assets/images/`)
- **Timeline** — `timeline`
- **Reasons I love you** — `reasons`
- **Promise cards** — `promises`
- **Secret notes** — `secrets`
- **Memory book pages** — `book`
- **Final message** — `reveal`

## Photos & video
- Replace the images in `assets/images/` with your own (keep the same file names, or update the paths in the CONFIG).
- Add a video at `assets/videos/memory.mp4` for the movie section.
- Add a song at `assets/music/song.mp3` for background music.

## Sections

Video → Promises → Memory book → Gift box surprise → Ending night sky.
Plus a floating music player, interactive heart cursor trail, and hidden secret envelopes 💌.
